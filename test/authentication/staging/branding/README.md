# Staging portal assets

Login and portal template hooks are adapted from go-authcrunch commit
`97408097f0d39c58be16c80131486edbbb358798`, `pkg/authn/ui/page_templates/basic/`.
The login uses provider-generated endpoints and the portal uses native logout.

Visual tokens and the unmodified `2713-red.svg` come from Hawk Eye revision
`535855c59b2d1f290c899ba1c834bdcc3d6db86e`, following its `docs/BRANDING.md`.
The mark remains on white with clear space, including in dark mode.

Self-hosted Latin WOFF2 fonts: `@fontsource/barlow@5.3.0` and
`@fontsource/open-sans@5.3.0`. Their license files are included alongside them.
No third-party font requests or JavaScript dependencies are required.
